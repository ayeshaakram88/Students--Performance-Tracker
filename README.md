# Students' Performance Tracker 

## Overview
**Students' Performance Tracker 2023** is a web-based system designed to manage and track students' academic performance, including assignments, quizzes, midterms, and final exams. The system provides role-based access for students, teachers, parents, and administrators, allowing them to enter, update, and review academic records efficiently.

## Features
- **Role-Based Access**: Four types of users—students, teachers, parents, and administrators—with different levels of access to manage and review performance data.
  - **Students**: Can view their academic records, including marks for assignments, quizzes, and exams.
  - **Teachers**: Can update students' records, including marks and attendance.
  - **Parents**: Can monitor their child’s academic progress.
  - **Administrators**: Have full access to manage all records and user accounts.
  
- **Student Records Management**: Allows entry, modification, and deletion of student performance data across multiple assessments.
  
- **User Authentication**: Separate login systems for each user type (Student, Teacher, Parent, Admin).

## Technologies Used
- **Node.js**: Backend JavaScript runtime for server-side logic.
- **SQL**: Database management for storing student records, grades, and user data.
- **HTML/CSS**: Frontend development for structuring and styling the web application.
- **JavaScript**: Client-side scripting for dynamic content and interactivity.
